##### Designing Based on Interviews

**Refining Algorithm Transparency and Privacy Features**

Building on the Social Media Algorithm Transparency App, this project focuses on integrating user feedback to improve functionality.

**Key Updates:**

**• Simplified Algorithm Controls:** Combined multiple pages into a single, intuitive interface for easier navigation.

**• Enhanced User Experience:** Improved clarity and interactivity based on peer feedback.

This iteration further empowers users with tools to manage their social media experience efficiently.
