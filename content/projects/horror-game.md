### Watch the gameplay!

If the video doesn't load, refresh the page!

<iframe src="https://www.youtube-nocookie.com/embed/SPucvRBjz-o" title="YouTube video" allowfullscreen=""></iframe>

This game is inspired by The Forest and Sons of The Forest. In, this game player tries to find multiple entrance points that takes it to different puzzles. In order to escape from island. The player needs to complete all the puzzles and get the reward from each puzzle. This game is in early development stage.

Check out the game files on GitHub!

[GitHub!](https://github.com/boraytuna/Horror-Game)
