Yesterday, I finished the design of Level 4 and Level 5. Initially, I planned to have 5 different levels that gets harder with each level. After designing the Level 5 the star score keeping and animation was broken so I had to rewrite the code to keep track of the stars collecsted in current level, and total stars collected after completing the game. So, it is safe to say that this game is finished. Today, I will build and run the game for the first time. I have never tried it for any other game either but I think it will be good thing to try and learn from. Also, I am starting a new game. It's going to be a horror game where the player needs to solve all the puzzles to escape the island. The game is mostly planned. I am excited to work on it.
